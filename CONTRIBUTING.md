# Contributing to FirmwareSight

Thank you for helping. FirmwareSight is a local-first firmware release workbench: a Rust core, a CLI (`fwsight`) and a Tauri 2 + React desktop app.

## Before you change code

Read [AGENTS.md](AGENTS.md). It holds the rules every contributor (human or automated) works under. The most important ones:

- **The Core decides; the UI displays.** Diff, gate, parser and ranking logic live in `crates/firmwaresight-core`, which has no Tauri, React, SQLite or Tokio dependency. The UI never re-implements or re-ranks Core results.
- **Evidence first.** Every fact is Observed, Derived, Declared or Unknown. An unknown value is never shown as 0 or as proof.
- **The technical baseline only changes through an ADR** (`09_ADR/`): no async-first Core, no SQLx, no HTTP client, no telemetry, no schema or migration change without one.
- **UI values come from design tokens** (`assets/design-tokens.json`, `DESIGN.md`).
- **New dependencies** must say why the standard library and existing dependencies are not enough, and must pass `cargo deny`.

## Build and check

```bash
python scripts/check.py
```

This runs everything CI runs: `cargo fmt`, `clippy`, the Rust tests, the frontend install, typecheck, lint, tests and build, the drift checks (design tokens, icons, IPC bindings, fixtures, goldens, version identity, baseline integrity) and `cargo deny`. A pull request should pass it locally first.

Golden files change only on purpose:

```bash
python scripts/update_goldens.py --confirm
```

Review every golden diff before you commit it.

## Fixtures

Fixtures under `fixtures/` are generated by scripts in `scripts/` and recorded in `fixtures/manifest.json` with their SHA-256. Never commit a firmware image, MAP or path from a private project. Generators refuse absolute host paths.

## Reporting bugs

Open a GitHub issue with:
- the FirmwareSight version (`fwsight --version`, or Help › About);
- the toolchain that built the firmware;
- the steps that reproduce the problem.

Do not attach proprietary firmware. A minimal reproduction, or the output of `fwsight analyze --json` with names removed, is enough.

Security issues: see [SECURITY.md](SECURITY.md).
