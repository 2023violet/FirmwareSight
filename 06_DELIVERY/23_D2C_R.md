## 2. Findings that change the plan

- **The ranking defect is in every comparison surface.** It shows in desktop Compare (the first ranking pick), the HTML and text report, the Markdown report and the release bundle report. A Pilot participant's first PT2/PT3 answer could be pointed at `.symtab`. It should be fixed **before** the Pilot build is frozen.
- **armlink names output sections after execution regions**, and two of them share a name (`RW_IRAM1`). Name pairing then shows them as added and removed. The D4 adapter ADR must decide the pairing key.
- **The Windows CI artifact for `5015143` expires on 2026-11-01.** The QA pass and the Pilot must download and keep the installer before then, or re-run CI on the same commit.
- **The local Keil MDK 5.43 / Arm Compiler 6.24 licence** makes synthetic D4 samples reproducible on this host. Real projects are still needed for RW compression, µVision builds, the C library and RTOS shapes.

## 3. Next engineering priorities

In order. Each one starts only when `.ai/ACTIVE_TASK.md` names it.

1. **Fix the section ranking (`24` option 2).** It is schema-neutral: rank only budget-charged sections, and list host-metadata growth separately and plainly. Add a Core test, regenerate the goldens on purpose, then review, CI and the Owner's fast-forward. It is small, it is a correctness issue, and it sits on the Pilot's main path.
2. **Run the Pilot minimum of the human QA pack** on the build that includes (1): Q1, Q2, Q8, Q16 at 125%, and installation on a non-Owner account. The other Q cases follow when an operator has time.
3. **Final Pilot approval and the first 3–6 sessions**, with `RECRUITMENT.md` and `MODERATOR_RUN_SHEET.md`. Report counts, never percentages.
4. **D4 ADR for the armlink adapter**, using `fixtures/elf/d4-armlink` and its cross-check. It decides the section pairing key and the RW-compression handling. Look for a real-project sample alongside. armlink stays `NOT_SUPPORTED` until the adapter, its ADR and its fixtures exist.
5. **D5 and D6 wait for evidence:** D5 needs Pilot demand for stack, component or symbol evidence; D6 needs closed QA risks plus the Owner's licence and signing decisions.
