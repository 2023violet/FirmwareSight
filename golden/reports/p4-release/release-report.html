The self-reference rule

SHA256SUMS coversevery bundle file except itself and the manifest
SHA256SUMS excludesSHA256SUMS, release-manifest.json
release-manifest.json coversevery bundle file except itself, SHA256SUMS included
release-manifest.json excludesrelease-manifest.json
A file cannot contain its own cryptographic hash without a fixed-point scheme, so no self-digest is faked: self_digest_written is false. no file carries its own digest; SHA256SUMS hashes the payload, release-manifest.json hashes the payload plus SHA256SUMS

Verifying this bundle without FirmwareSight

Every file here is a plain file. Any SHA-256 tool and any text editor is enough. The check below proves that the bytes match the lists — an integrity and consistency statement about the bundle as written. It says nothing about who wrote it, and nothing in this bundle is a signature.

  1. List the directory. It must contain exactly the files release-manifest.json indexes, plus that manifest itself, and no temporary or hidden file.
  2. Recompute the SHA-256 of every file named in SHA256SUMS and compare it with the digest on that line. On a POSIX host one command does the whole list: sha256sum -c SHA256SUMS.
  3. On Windows, Get-FileHash -Algorithm SHA256 <path> prints the same digest in upper case; lower-case it before comparing, because both lists are written in lowercase hex.
  4. Compare every line of SHA256SUMS with the entry of the same path in the files[] array of release-manifest.json. Digests and sizes must agree, and the manifest must additionally carry an entry for SHA256SUMS itself.
  5. Confirm that neither list contains a blank digest, an all-zero digest, or the digest of the file it sits in. There should be none of those, and looking for them is what makes the rule in the table above checkable rather than a claim.
  6. Open analysis.json, gate-results.json and accepted-reviews.json as plain JSON. Each names the schema it is an instance of, and the manifest's extensions block states which schema majors this bundle was written against.
