# Exploratory Pilot Register

Only sessions that actually happened are counted. A planned, scheduled or cancelled session is listed under "Invitations" and never counted.

## Counters

```text

Pilot build named (commit + SHA-256)    = NONE
sessions held                           = 0
  of which OUT_OF_COHORT                = 0
participants moved to the Pilot pool    = 0   (each is permanently ineligible for formal V1)
```
