# FirmwareSight Post-MVP 探索开放问题裁决记录

## 0. 卷首边界声明

1. **裁决范围与性质**：本记录收录三轮《FirmwareSight 正式产品功能探索》交付稿 §8 全部 **27 条**开放问题的最终裁决——第一轮《分析结果可视化与文档导出》6 条、第二轮《端口扩展与深度体验》11 条、第三轮《真需求功能全景扫描》10 条。用户已拍板：**27 条全部按各条所附默认建议定案**（第一轮 6 条、第二轮 11 条此前已确认；第三轮 10 条为 2026-09-27 本轮新确认）。
2. **Post-MVP 方向性定案**：27 条均为 Post-MVP 方向性定案，**不改变 MVP 范围（MVP 一寸不扩）、不改变 Active Task = NONE、不触发任何功能创建**。当前唯一合法下一步仍是 P0 Technical Vertical Slice。各条所附「建议阶段」（P1/P2/P4/Post-GA 等）仅为路线图落位，仅当候选未来被采纳并通过治理后才生效。
3. **唯一权威档案**：本记录为三轮开放问题的**唯一权威裁决档案**。三份交付稿 §8 及其他既有文档中相应问题的「待拍板/悬置」状态，自本记录生效起一律**以本记录为准**；既有文档正文不逐处回改。
4. **候选 ≠ 承诺，实施须过门禁**：定案确认的是「方向与处置口径」。§2 后续动作清单中一切实施动作，在触发时机到达后仍须逐项过 **Scope Creep 四问（FS-PRD-004）**与开发纪律三问；技术基线变更走 **ADR**；新依赖过 FS-TECH-012 / FS-ENG-006 准入；设计条款随设计资产升版入册 DESIGN.md（**本轮不动设计资产**）；Growth 项过「四不破坏」试金石（local-first / deterministic core / evidence provenance / explicit unknown）；一切候选必须挂靠四动词，不能成为第五动词。
