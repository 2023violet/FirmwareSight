【目标】
在现有 Rust Core + Tauri 2 + React 桌面架构中，使全主工作流、Help/诊断可见文案、Settings、错误恢复采用离线 zh-CN/en UI 语言。用户偏好 language=system(default)|zh-CN|en，切换即时生效、跨重启保留；系统语言不支持时退回 English。严格保持 FirmwareSight 现有专业工具的紧凑布局、Evidence 分类与稳定发布契约。

【先读权威，禁止根据记忆改码】
AGENTS.md、.ai/{README,CURRENT_STATE,DECISIONS,ACTIVE_TASK}.md、产品 v0.2 决策文档、已落地 ADR-0031、DESIGN.md、03_DESIGN/*、assets/design-tokens.json、已有 B1-U1/U2 的 preferences.rs、Settings、App、IPC、启动恢复/诊断、全部非 test TSX 页面、CLI spec、Gate 状态语义、Review/Release 报告边界。核对实测代码，不能盲信“436 处字面量”“150 行 Catalog”的估计。

【必须先作出的架构判定】
1. 比较两种可实现方案：受控 typed Catalog（项目内极小实现）与 i18next/react-i18next。对比 key 可追踪性、语言回退、插值与转义、复数/日期未来扩展、动态错误语句、打包体积、第三方许可证、离线性、单元测试和维护成本。不可直接把“零依赖”当作决定；约 436 处字符串、9 命名空间时“150 行代码”不能覆盖翻译实际维护量。选一条后记录最小决议、替代方案和可测试的理由。
2. Preferences schema 以实际已落地状态为准。若当前 B1-U2 是 schema_version=2，B1-U3 若需持久化 language，可选择安全的可选字段扩展或显式升级 v2→v3。必要时按现有存储/ADR 规范立一份最小 ADR-0032；先让读取器兼容 v1/v2，再允许新写入，保留后向兼容、未来版本拒绝写入、受损文件隔离/恢复、原子写及 Reset 语义。版本数字不能由 Agent 猜测。
3. language 不进入 Core、GateContext、Snapshot identity、policy_sha256、Gate run id、Release id、manifest、portable reports、CLI JSON、ErrorCode/exit code；不引入第二套 firmware project policy，不引入联网/遥测/账号。
4. 错误文本不能通过 Rust 英文句子的 split/replace 或简单断句翻译；使用稳定 code + 受控参数形成 UI 文案，留原始 code 可复制与定位，绝不能泄漏宿主绝对路径；未知码 fallback 保持事实准确。

【具体开发范围】
A. Language resolver：system 使用系统/桌面公开可用的语言信号，标准化 zh-CN、en；对 zh-HK/zh-TW 不能暗称已完整繁体支持，对不支持语言退回 English。记录 OS 当前语言变化能否实时检测，不能实现时须明确“启动/切回 System 时刷新”的真实合同，而不是空口承诺。
B. Catalog：至少 common、analyze、compare、gate、release、history、settings、help、errors 九个命名空间；Overview 共用 common 或额外 namespace 需明确。在编译或 CI 中检测英文和中文缺失键、重复键、占位符错位、意外 raw string；禁止句子拼接、HTML 直接注入与未经处理的外部数据插值。
C. UI：逐页完整覆盖导航、PageHeader、操作按钮、工具提示、空态、加载态、错误、表格标题、筛选/分页、诊断、Settings、Review 接受理由、Bundle 的限制说明。固定状态代码 PASS/REVIEW/BLOCK/UNKNOWN/N/A 和 Observed/Derived/Declared/Unknown 不翻译机器常量；中文可加解释，但不能改变状态含义。Section/Symbol、地址、Hash、文件路径、规则 ID、数值、项目和构建名称原样展示。
D. Settings 增加真实 language 选择；支持 system/中文/English 三态，保存失败与 Reset 错误语义如实反馈，跨页面语言同步；不渲染未实现的未来设置。RTL 不做虚假承诺。
E. 报告/数据面：portable analysis/diff/gate-results/release-manifest、稳定 Golden、自包含 release-report.html 维持原有固定语言与 byte identity；桌面 UI 语言不改变 CLI JSON 或 Bundle 的任何文件字节。请对固定 Fixture 实际比较语言切换前后的 digest/runId/golden，不仅 UI 断言。
F. 交互：避免布局因中文/英文长文案溢出；1024×720/1440×900、100%/125%/150% 可得的实测矩阵；键盘焦点、ARIA 名称、错误恢复、表格操作、深浅色中的中文可读性。主题持久化/语义不得回归。
