## Recommended duration

30–45 minutes per participant.

Reserve additional moderator time after each session to finish the evidence record before the next session.

## Scheduling rule

Do not overbook sessions so closely that moderator notes are reconstructed from memory later.

## Prototype consistency

All normal Batch A sessions use the same prototype version.

A mid-batch hotfix is permitted only for a Critical Execution Blocker and must be logged with affected participant IDs.
