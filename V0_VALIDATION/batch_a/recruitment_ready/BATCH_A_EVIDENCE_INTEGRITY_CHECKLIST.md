# Batch A Evidence Integrity Checklist

Before counting PA-00X in Formal N:

- [ ] participant is a real human
- [ ] participant is external to FirmwareSight project/design execution
- [ ] participant meets eligibility
- [ ] session used approved task wording
- [ ] no pre-teaching of Evidence/Gate/Bundle semantics
- [ ] prototype started at STATE A
- [ ] moderator interventions are logged
- [ ] quotes are verbatim or explicitly marked non-verbatim
- [ ] task outcome is evidence-coded, not impression-coded
- [ ] commercial signal is not inferred from generic praise
- [ ] confidential data is not stored
- [ ] source provenance is recorded

If any mandatory item fails:
do not silently count the participant in n/N.
