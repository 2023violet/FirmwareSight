# Metrics

## External sample

Eligible external participants completed: `0 / 8 minimum`

Therefore no V0 completion ratio is reported.

## Required metrics once sessions start

Report actual numerator/denominator:
- T1 readiness comprehension n/N
- MAP transition comprehension n/N
- Analyze completion n/N
- Compare completion n/N
- Review vs Block comprehension n/N
- Unknown comprehension n/N
- Declared vs Observed comprehension n/N
- Bundle purpose comprehension n/N
- Parse recovery completion n/N
- History/evidence discoverability n/N
- return intent n/N
- price-anchored willingness n/N
- team Pilot willingness n/N

Also report:
- median completion time;
- first-click correctness;
- wrong-turn counts;
- backtracks;
- moderator interventions.

No percentage should be reported without its n/N.
